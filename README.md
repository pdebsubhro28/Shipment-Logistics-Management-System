# Shipment & Logistics Management System

## Overview
This project is an end-to-end Shipment & Logistics Management System developed using SQL, Python, Pandas, SQLite, and Plotly. It demonstrates data cleaning, database creation, SQL analysis, and interactive data visualization using the Global Superstore dataset.

## Features
- Data cleaning using Pandas
- SQLite database creation
- SQL queries for business insights
- Interactive data visualization with Plotly
- Jupyter Notebook implementation

## Technologies Used
- Python
- Pandas
- SQLite
- SQL
- Plotly
- Jupyter Notebook

## Project Files
- `Shipment & Logistics Management System.ipynb` – Main project notebook
- `shipment_logistics.db` – SQLite database
- `orders_clean.csv` – Cleaned orders data
- `people_clean.csv` – Cleaned people data
- `returns_clean.csv` – Cleaned returns data
- `global_superstore_2016.xlsx` – Original dataset

## Project Workflow
1. Data Cleaning
2. Database Design
3. SQL Analysis
4. Data Visualization
5. Business Insights
